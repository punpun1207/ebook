Web Ebook (Test Project)

Đây là một dự án web thử nghiệm dùng để hiển thị và đọc sách điện tử (ebook). Dự án được tạo ra nhằm mục đích học tập và test các tính năng cơ bản của một trang web đọc sách.
1. Tính năng
- Hiển thị danh sách các cuốn sách.
- Giao diện đọc sách trên trình duyệt.
- Thiết kế đơn giản, dễ sử dụng.

2. TTS
- TTS mới ổn ở epub tiếng Anh, đang thử chức năng chạy nền.
